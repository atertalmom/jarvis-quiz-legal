JARVIS Quiz

What the product does

JARVIS Quiz helps creators turn quiz ideas into ready-to-review TikTok drafts. It is not a consumer social network and does not display TikTok posts on this website.

Local video generation

Quiz videos (9:16) are rendered on the creator’s computer. Processing stays local before any TikTok upload.

Official OAuth login

Each creator connects their own TikTok account through TikTok Login Kit (OAuth 2.0). No shared credentials.

Inbox draft only

Uploads use Content Posting API video.upload to send a draft to TikTok inbox. Never auto-publishes to the feed.

Manual publish

The creator opens TikTok on their phone, reviews the draft, edits caption, and taps Publish themselves.

End-to-end flow

How it works

This is the same flow shown in our TikTok for Developers sandbox demo video.

1

Create the quiz MP4 on desktop

Generate a vertical quiz video locally with the JARVIS Quiz pipeline.

2

Open the local panel

Run the desktop panel at http://localhost:3455 and choose Connect TikTok.

3

Authorize with Login Kit

TikTok OAuth asks the creator to grant user.info.basic and video.upload for their own account.

4

Send draft to inbox

With consent, the panel uploads the file via Content Posting API to TikTok inbox as a draft.

5

Publish in the TikTok app

The creator reviews on mobile, edits caption/effects if needed, and publishes manually.

FAQ

Common questions reviewers and creators ask.

Does JARVIS Quiz auto-publish to TikTok?

No. Videos are uploaded as inbox drafts only. The TikTok user must open the app and publish manually.

Which TikTok products/scopes are used?

Login Kit (OAuth) and Content Posting API with scopes user.info.basic and video.upload.

Is this website a TikTok client feed?

No. This site documents the product, Privacy Policy, and Terms. It does not embed or display TikTok posts.

Where does OAuth redirect?

Web redirect: callback.html. Desktop panel also supports http://localhost:3455/callback/ for local PKCE testing.
