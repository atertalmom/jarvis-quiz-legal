JARVIS Quiz

Gerador automático de vídeos de quiz para TikTok, Reels e Shorts

Crie vídeos verticais completos (9:16) com pergunta, opções, suspense, revelação e call-to-action. Envia direto como rascunho para o TikTok.

O que o JARVIS Quiz faz

É uma ferramenta desktop que gera automaticamente vídeos de quiz no formato vertical. Tudo acontece localmente no seu computador. O vídeo final é enviado como rascunho para a sua conta do TikTok usando a API oficial — nunca publica automaticamente.

Funcionalidades

  • Geração automática de quizzes educativos ou virais
  • Formato 9:16 otimizado para TikTok, Reels e Shorts
  • Narração opcional com voz natural
  • Envio direto como rascunho no TikTok (Content Posting API)
  • Integração oficial com TikTok for Developers
  • Processamento local — sem upload para servidores externos
